# Портфолио Светланы Мальченковой

Сайт-портфолио дизайнера корпоративных презентаций. Главная страница знакомит со Светланой, опытом и направлениями работы; девять отдельных страниц подробно показывают задачи, роль и решения по проектам.

## Локальная проверка

Требуется Node.js 22 или новее.

```bash
npm run build
npm test
```

Готовый сайт создаётся в папке `dist`. Публикация в GitHub Pages запускается автоматически после изменений в ветке `main`.
